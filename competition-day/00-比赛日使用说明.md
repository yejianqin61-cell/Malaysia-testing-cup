# 比赛日脚手架 · 使用说明（TeaYeah）

这个文件夹是比赛当天直接用的东西。原来 `templates/` 里的模板保留不动；这里是预填好、能直接复制粘贴的版本。所有要提交的内容都是英文。

| 文件 | 是什么 | 什么时候用 |
|---|---|---|
| 01-test-plan.md | 测试计划，已经预填约 70%（策略、技术、环境、准入/退出准则、严重程度标准、项目风险） | 0–15 分钟：只填 [FILL] 部分 |
| 02-summary-report.md | 总结报告"大报告"，覆盖全部 6 个评分项 + AI 使用说明 | 第 15 分钟开始边测边填，第 145 分钟收尾 |
| 03-ai-prompts.md | 英文提示词库 P0–P9，按比赛流程排序 | 每个阶段复制对应的那条 |
| 04-test-ideas-checklist.md | 常见功能的通用测试点 + 非功能检查清单 + "不算 bug"清单 | 设计用例、探索测试时挑着用 |
| 05-bug-writing-guide.md | 严重程度标准、bug 报告模板、标题公式、英文句库、提交前检查清单 | 每写一个 bug 都看一眼 |
| ../automation/ | B 层通用自动化检查（性能 / axe / 多端截图 / 报错收集 / 冒烟），输出直接粘进 NonFunctional 表；配合提示词 P10/P11 | **仅当讲解明确允许自动化**；见 automation/README.md |
| 06-TeaYeah-workbook.xlsx | 共享工作簿：Risks / TestCases / Defects / NonFunctional / AI_Log / Stats（自动统计） | 比赛前导入 Google Sheets，两人同时填 |

## 赛前准备（周五模拟赛之前做完）
1. 把 `06-TeaYeah-workbook.xlsx` 上传到 Google Drive → 用 Google Sheets 打开 → 分享给队友（可编辑）。下拉菜单和公式会保留。
2. 在 01 和 02 里填好队友姓名。
3. 两人都读一遍 05 的严重程度标准，确保评级口径一致。

## 比赛当天节奏
- 10:00 新开一个 AI 对话，粘贴 P0。
- 0–15 分钟：一起点一遍网站 → P1 → P2 → 把风险填进 Risks 表和 01 第 3 节 → 提交测试计划。
- 15–35 分钟：每人负责自己的高风险项，用 P3 生成用例，粘贴到 TestCases 表，**人工删改**。
- 35–145 分钟：执行，填 status。发现问题 → 先填 Defects 表（Suspected）→ P5 质疑 → 另一个人复现 → 改成 Verified → 提交 → 改成 Submitted 并填 platform_id。
- 每 30 分钟两人同步 2 分钟；第 90 分钟用 P7 查漏。
- 145 分钟：看 Stats 表的数字 → P8 起草总结 → 人工核对每个数字 → 12:50 前全部提交。
- 全程：每用一次 AI，AI_Log 记一行（这是 AI 加分的证据）。

## 注意
- 提交平台的具体栏目当天才知道。平台若有单独栏目，从 01/02 里拆开复制；没有的话，02 就是完整报告。
- 粘贴给 AI 之前，去掉密码、token、个人信息。
- AI 只负责出主意和写作，不让 AI 操作被测网站（是否允许当天确认）。
